# Controle Financeiro

Projeto de curso — app de controle de gastos.

## Etapas
1. Frontend básico (sem backend) — feito
2. Formulário de cadastro (local)
3. Backend (server, database, routes, controller)
4. Tabela do banco
5. Conexão React → API → SQLite
6. Melhorias (filtro avançado, validação, confirmação, estatísticas)

## Rodando o frontend
cd frontend
npm install
npm run dev
